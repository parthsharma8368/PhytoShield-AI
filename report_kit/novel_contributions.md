# Novel contributions — facts, evidence, honest scope

Write each as one bullet in your own words. Claim only what the evidence column supports.

| # | Contribution | Evidence in repo | Honest scope (say this in the report) |
|---|---|---|---|
| 1 | **Duplicate-leakage audit and fix.** The original PlantVillage copy used here contained byte-identical images in several folders; the old random split put the same file in train and test. Content-hash (MD5) deduplication was added to the splitter, a regression test was written, and the model was retrained. | `data/dataset_splitter.py` (`deduplicate_by_content`), `tests/test_dataset_integrity.py`, `reports/study/dataset_audit.json`, backups in `*/legacy_leaky_split/` | Removes exact copies only. Near-duplicates (same leaf photographed twice) are not detected, so the accuracy is still optimistic. |
| 2 | **Seven attribution engines under one protocol.** Grad-CAM, Grad-CAM++, Saliency, SmoothGrad, Integrated Gradients, SHAP (occlusion) and LIME are run on the same images, the same model, the same deletion/insertion test, with a random-attribution baseline and a Wilcoxon signed-rank test. | `experiments/run_xai_study.py`, `table_xai_summary`, `fig_xai_faithfulness*` | Sample of the test set (stratified, N per class), not all 3,107 images. LIME uses a smaller sample because it is slow. |
| 3 | **Six-metric explanation-quality framework** (faithfulness deletion/insertion, stability, consistency, robustness, sparsity, localization) reported per method and per class. | `explainability/metrics.py`, `experiments/run_xai_study.py` | Localization uses a green-pixel (ExG + Otsu) leaf mask, not expert lesion masks. The composite index weights (0.25/0.20/0.15/0.15/0.10/0.15) are a design choice, not learned or validated. |
| 4 | **Counterfactual check.** The suspected lesion area is in-painted and the model is re-run; a large confidence drop supports that the model used that region. | `explainability/counterfactual.py`, `experiments/run_failure_analysis.py` | Simple in-painting; not a causal proof. |
| 5 | **Rule-based concept scoring.** Colour/texture rules turn the image into botanical concept scores (e.g. chlorosis, necrosis) shown next to the prediction. | `explainability/concept_explainer.py` | **Not** a trained Concept Bottleneck Model. Do not call it one. Scores are heuristics and were not validated against expert labels. |
| 6 | **Uncertainty and abstention.** MC-Dropout (p=0.3 in the classifier head, 10 passes) plus calibration (ECE/MCE/Brier) and a selective-prediction curve show how accuracy improves when the model abstains on uncertain images. | `experiments/run_base_eval.py`, `fig_selective_prediction`, `table_error_detection` | Dropout is only in the head; this is an approximation of Bayesian uncertainty. |
| 7 | **Robustness scenarios.** Accuracy and explanation stability under noise, blur, brightness, JPEG, occlusion and background removal. | `experiments/run_perturbation_study.py`, `table_perturbation` | Synthetic perturbations; not real field photographs. |
| 8 | **Failure-case study with XAI.** Every misclassified test image is explained by four engines plus a counterfactual, and grouped by cause. | `experiments/run_failure_analysis.py`, `failure_cases.csv`, `failures/` | Cause grouping is manual reading of the figures plus simple rules. |
| 9 | **Progressive three-stage inference** (instant label → heatmap → full explanation) so the user sees a diagnosis fast and detail loads in the background. | backend prediction route and `frontend/src/pages/Analyze.tsx` | Engineering contribution; latency numbers come from `reports/model_benchmarks.json`. |
| 10 | **Blinded human-expert evaluation protocol** (cases, rating form, answer key, analysis script). | `experiments/expert_packet.py`, `analyze_expert_feedback.py` | **Results are pending** until a real plant-pathology expert fills the form. Do not invent ratings. |
