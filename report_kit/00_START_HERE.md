# Report kit — how to use it

The professor requires a report "without plagiarism and AI". This kit gives you **facts, numbers, figures, tables and a
checker**. It deliberately does **not** give you finished paragraphs. You write the sentences yourself, in your own words,
from the facts. That is the only way the report is yours, and the only way you can defend it in the viva.

## Workflow

1. Run the experiments (see `reports/study/RUN_ORDER.md` once generated). Every number in the report must come from a file in `reports/study/`.
2. Read `fact_sheet.md` (generated, real numbers) and `writing_guide.md` (what each heading must contain).
3. Write the draft in `report_draft.tex` or Word, one section at a time, from memory of what you understood — not by copying kit text.
4. Cite as you write (`\cite{key}`), using only papers you actually opened. Fix every entry in `references.bib` against the publisher / arXiv page.
5. Check locally, as often as you like:

   ```bash
   python -m experiments.originality_check report_draft.tex
   ```

   It flags (a) 8+ word runs copied from this project's own text, (b) citations missing from the reference list, (c) quoted numbers that no results file contains.
6. Run the university's official plagiarism tool and AI-writing check on the final PDF. A local script cannot certify anything; only the official tool counts.
7. Rehearse with `simple_explanations.md` until you can explain each section in two sentences.

## Rules that keep the report original and honest

- Never paste text from papers, blogs, READMEs or chat tools. Paraphrase after closing the source, then cite it.
- Every claim about other work gets a citation. Every number about this project gets a source file.
- Do not quote metrics you did not measure. Items not evaluated are written as "not evaluated".
- Report limitations plainly (list in `writing_guide.md`). Honest limits raise the grade; hidden ones sink the viva.
- Figures and tables in `reports/study/` are generated from your own runs — reuse them freely and mention the script that made each.

## Files

| File | Purpose |
|---|---|
| `fact_sheet.md` | Real numbers from the clean-split run (generated by `experiments/build_fact_sheet.py`) |
| `writing_guide.md` | For each required heading: what to cover, which figure/table to use, what to avoid |
| `comparison_table.md` | Draft rows for the related-work table — every cell must be verified against the paper |
| `novel_contributions.md` | Pointwise contributions, each with evidence file and an honest scope note |
| `simple_explanations.md` | Plain-language explanations and viva Q&A |
| `references.bib` | Candidate references — verify each one before citing |
